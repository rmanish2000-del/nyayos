# WAVE_0

Priority: P0
Goal:
Create a trustworthy evidence operating system.

Features:

1. Provenance Engine
   - Every proposition linked to source
   - Source type:
     - Original
     - Founder
     - Third Party
     - Generated
     - AI Analysis

2. Generated Content Firewall
   - Generated content cannot become evidence
   - Generated content visually marked

3. Contradiction Registry
   - Date conflicts
   - Amount conflicts
   - Role conflicts
   - Version conflicts

4. Missing Material Registry
   - Referenced but absent
   - Referenced but inaccessible
   - Referenced but unreadable

5. Stable Document IDs
   - Permanent internal IDs
   - Annexure changes do not affect IDs

6. Case Isolation Layer
   - No cross-case retrieval by default
   - Separate indexes

7. Correction Propagation
   - Update downstream outputs automatically

8. Stale Output Detection
   - Detect outputs invalidated by newer evidence

Success Criteria:
- No generated output treated as evidence
- Contradictions visible
- Missing documents visible
- Cases isolated
